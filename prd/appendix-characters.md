# 付録 A. キャラクター一覧（原典）

**このリストが登場人物データの原典である。** 実装（[`server-ts/charactersMaster.ts`](../server-ts/charactersMaster.ts)、
seed、`backfill_readings` マイグレーション）は本表に従う。両者が食い違った場合、本表が正しい。

収録の基準・列の意味は [01-domain.md](./01-domain.md) §1 を参照。

---

## 規約

- **収録基準は「シリーズの登場人物を網羅的に」**。恋愛攻略の可否で絞らない。
  男性キャラ・女性キャラ・公式サイトのキャラ一覧に載らない人物（益田義人）も含む。
- `series` は作品（GS1〜GS4）、`sort` はシリーズ内の**公式順**。**`(series, sort)` が公式順を定める**
  （同票時のタイブレーク・凡例順・一覧表示順はすべてこれに従う。[05](./05-analysis.md) §4）。
- `name` は表示名かつドメイン識別子（varchar(20)）。DB では `Characters.name` が UNIQUE で、
  投票・集計はすべてこの名前を FK 参照する。
- `reading` はひらがなの読み仮名（姓名の区切りなし、varchar(40)）。**キャラ検索専用**で集計には使わない。
  - ⚠️ **直感に反する読みが多い**（「きじょうまどか」「さくらいこういち」「かざまりょうた」「つくし」など）。
    Wikipedia の各作品記事で検証済み（2026-07 時点）。**変更するときは必ず出典に当たること。**

**合計 61 人**（GS1: 18 / GS2: 17 / GS3: 13 / GS4: 13）。

## 変更手順

キャラクターを追加・改名する場合（GS5 のリリース時など）:

1. **本表を先に更新する**（原典）。読みは出典に当たって確認する。
2. `server-ts/charactersMaster.ts` を本表に一致させる。
3. `pnpm db:generate` でマイグレーションを作り、`pnpm db:migrate` で適用する。
   - 既存 DB へのキャラ追加は INSERT、改名は `Characters.name` の UPDATE
     （FK が `ON UPDATE CASCADE` なので投票データは追随する）。
   - キャラの**削除はできない**（FK が `ON DELETE RESTRICT`）。投票された履歴を壊さないための意図的な制約。
4. GS5 を足す場合は、プレイ状態の書き込みが series をハードコードしていないか確認する（[04](./04-voting.md) §3.1）。
5. **人数を書いている文言を直す**。`next/src/lib/structuredData.ts` の `SITE_DESCRIPTION` が
   「登場人物 61 人」と持っている（metadata の description と JSON-LD が同じ文を使う。[08](./08-frontend.md) §5.1）。
